# makefun-u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a

One original one-line joke, written for make.fun's ["One Line, One Laugh"](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty. The program writes the joke to `/output/entry.txt`.

> My phone's battery dies at 20% now. I respect it — it's the only thing in my life that sets boundaries.

## Run it

```sh
node main.ts
```

Requires Node 22.6+ (Node 22.18+ runs TypeScript directly). The joke is checked to be 1–140 characters and a single line before it is written.
